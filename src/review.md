# Laravel Lesson レビュー①

## Todo一覧機能
- まず、web.phpで/todoのルートを定義します。その後、TodoControllerにindexメソッドを作成し、データベースからTodoのリストを取得してビューに渡します。最後に、resources/views/todo/index.blade.phpでリストを表示するビューを作成します。これで、Todo一覧が表示されるようになります。

### Todoモデルのallメソッドで実行しているSQLは何か
- Todoモデルのallメソッドで実行しているSQLは、SELECT * FROM todos`です。

### Todoモデルのallメソッドの返り値は何か
- Todoモデルのallメソッドの返り値は、Illuminate\Database\Eloquent\Collection`です。

### 配列の代わりにCollectionクラスを使用するメリットは
- Collectionクラスを使うと、配列よりも簡単にデータを操作できるようになります。例えば、複数の操作を一度に行えるメソッド(メソッドチェーン)があり、コードが短くなり、読みやすくなります。さらに、エラーが少なく、データの操作を一貫して行えるので、保守性も高まります。

### view関数の第1・第2引数の指定と何をしているか
- view関数の第1引数は、表示するビュー（テンプレート）の名前を指定します。例えば、'todo.index'のように指定すると、resources/views/todo/index.blade.phpというファイルが表示されます。

- 第2引数は、ビューに渡すデータを指定します。これにより、コントローラからビューにデータを送ることができます。例えば、['todos' => $todos]とすると、$todosというデータがビュー内で$todosとして使えるようになります。

簡単に言うと、第1引数はどのビューを表示するか、第2引数はそのビューに渡すデータを指定しています。

### index.blade.phpの$todos・$todoに代入されているものは何か
- $todos には、データベースから取得した「Todo」の一覧が代入されています。例えば、Todo::all() で全てのTodoが取得され、その結果が $todos に入ります。
$todo は通常、1つのTodoアイテムを指します。例えば、特定のTodoを取得した場合に、その1件のデータが $todo に代入されます。

## Todo作成機能
- ユーザーが「Todo作成」ボタンをクリックして、入力フォームが表示されます。
- フォームでTodoの内容を入力し、「作成」ボタンを押すと、データがサーバーに送信されます。
- コントローラーがそのデータを受け取り、モデルを使ってデータベースに保存します。

### Requestクラスのallメソッドは何をしているか
- Request クラスの all メソッドは、HTTPリクエストで送信された全ての入力データを配列として取得します。これには、フォームから送信されたデータやURLのクエリパラメータなどが含まれます。

### fillメソッドは何をしているか
- fill メソッドは、モデルに複数の値を一度に設定するためのものです。例えば、フォームから送られてきたデータをモデルにまとめて入れることができます。

### $fillableは何のために設定しているか
- $fillable は、モデルにどの属性を一度に設定できるかを指定するために使います。これを設定することで、意図しないカラムが一度に変更されることを防ぎます。
- 例えば、ユーザーが送信したフォームからのデータをモデルに保存する際、$fillable に指定されたカラムだけが更新されます。これにより、悪意のあるユーザーが予期しないカラムを変更することを防ぐことができます。

### saveメソッドで実行しているSQLは何か
- save メソッドは、新しいレコードが作成されるか、既存のレコードが更新されるかを自動的に判断して、適切な SQL を実行します。
### redirect()->route()は何をしているか
- redirect()->route() は、指定した名前付きルートにリダイレクト（転送）するためのメソッドです。
## その他

### テーブル構成をマイグレーションファイルで管理するメリット
- マイグレーションファイルを使ってテーブル構成を管理することで、データベースの変更履歴をコードとして記録でき、チームで一貫性を保ちながら作業ができます。また、誤った変更を元に戻すことが簡単になり、異なる環境で同じデータベース構成を適用できるため、環境間の差異を減らすことができます。

### マイグレーションファイルのup()、down()は何のコマンドを実行した時に呼び出されるのか
- up()メソッドは、php artisan migrateコマンドを実行したときに呼ばれ、データベースにテーブルを作成したり、カラムを追加したりするなどの変更を実行します。down()メソッドは、php artisan migrate:rollbackコマンドを実行したときに呼ばれ、up()メソッドで行った変更を元に戻します。例えば、テーブルを削除したり、追加したカラムを削除したりします。
### Seederクラスの役割は何か
- Seederクラスは、データベースに初期データを挿入するためのクラスです

### route関数の引数・返り値・使用するメリット
- route 関数は、名前付きルートのURLを生成するもので、アプリケーション全体でURLを一貫して使用でき、ルートのURLを変更する際に1か所でのみ更新すれば済むため、メンテナンスがしやすくなります。

### @extends・@section・@yieldの関係性とbladeを分割するメリット
- @extends、@section、@yieldは、LaravelのBladeテンプレートエンジンで、ビューを分割して再利用するために使用します。

### @csrfは何のための記述か
- @csrfは、LaravelのBladeテンプレートでCSRF攻撃を防ぐために使用する記述です。

### {{ }}とは何の省略系か
- {{ }}は、LaravelのBladeテンプレートでPHPのecho文を省略するための構文です。中に書かれた変数や式をそのままHTMLに出力する役割を持ちます。
